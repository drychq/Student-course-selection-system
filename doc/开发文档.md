# 选课系统开发文档

## 1. 项目概述
### 1.1 项目背景
系统采用C++语言开发，使用面向对象的设计理念，确保代码的可维护性和可扩展性。

### 1.2 项目目标
- 实现学生选课，查看成绩
- 提供教师管理课程，导入成绩
- 支持课程信息的维护
- 确保数据的持久化存储
- 提供友好的用户界面

## 2. 开发历程
### 2.1 开发思路
1. 需求分析阶段
   - 通过用例分析确定核心功能
   - 设计数据模型和类之间的关系
   - 规划系统架构和技术选型

2. 设计阶段
   - 采用自顶向下的设计方法
   - 先搭建框架，后完善细节
   - 注重模块间的解耦和接口设计

3. 实现阶段
   - 按照功能模块逐步实现
   - 及时重构优化代码

### 2.2 技术难点及解决方案
#### 2.2.1 内存管理
难点：对象生命周期管理复杂、容易发生内存泄漏、对象共享和传递问题
解决方案：使用智能指针管理对象、采用RAII原则、明确对象所有权

#### 2.2.2 数据持久化
难点：数据格式的设计、文件操作的异常处理、数据一致性保证
解决方案：采用结构化的文件格式、使用try-catch处理异常、实现数据完整性检查

## 3. 需求分析
### 3.1 功能需求
#### 3.1.1 学生管理
- 添加/删除学生信息
- 查询学生详细信息
- 管理学生选课记录
- 记录学生成绩

#### 3.1.2 教师管理
- 教师信息维护
- 课程分配
- 查看所授课程

#### 3.1.3 课程管理
- 课程信息维护
- 课程查询
- 选课管理
- 成绩录入

### 3.2 非功能需求
- 数据安全：确保数据完整性和安全性
- 可用性：提供直观的用户界面
- 可维护性：采用模块化设计
- 可扩展性：支持未来功能扩展

## 4. 系统设计
### 4.1 总体架构
系统采用面向对象的设计方法，主要包含以下核心类：
- `System`：系统核心控制器
- `Student`：学生信息管理
- `Teacher`：教师信息管理
- `Course`：课程信息管理
- `Menu`：用户界面管理

### 4.2 核心类设计
```cpp
class System {
    // 核心数据结构
    std::vector<std::shared_ptr<Student>> m_students;
    std::vector<std::shared_ptr<Teacher>> m_teachers;
    std::vector<std::shared_ptr<Course>> m_courses;
    
    // 主要功能接口
    void addStudent(const std::string& name, int id);
    void addTeacher(const std::string& name);
    void addCourse(const std::string& name, int id, const std::string& desc);
    
    // 数据持久化
    void saveData(const std::string& dirname);
    void loadData(const std::string& dirname);
};
```

### 4.3 接口设计
- 用户界面接口
- 数据管理接口
- 查询检索接口
- 数据持久化接口

## 5. 实现细节
### 5.1 关键技术
- 智能指针管理内存
- 文件IO实现数据持久化
- 面向对象封装业务逻辑
- 异常处理确保系统稳定

### 5.2 代码规范
- 类名采用大驼峰命名
- 成员函数采用小驼峰命名
- 私有成员变量前缀m_
- 使用const修饰不可变参数
- 合理使用注释说明功能

## 6. 系统交互
### 6.1 交互场景
1. 学生选课流程：学生登录(输入姓名，学号) → 查看可选课程 → 选择课程 → 确认选课 → 系统更新数据
2. 教师管理流程：教师登录（输入姓名） → 查看所授课程 → 录入成绩 → 保存更新

### 6.2 用户界面
```cpp
void MainMenu::display() {
    cout << "\n--- 课程选择系统 ---\n";
    cout << "1. 学生管理\n";
    cout << "2. 教师管理\n";
    cout << "3. 课程管理\n";
    cout << "4. 数据管理\n";
    cout << "5. 退出\n";
    cout << "请输入您的选择: ";
}
```

### 6.3 操作流程
1. 系统启动，显示主菜单
2. 用户选择功能模块
3. 进入相应的功能界面
4. 执行具体操作
5. 显示操作结果
6. 返回主菜单或继续操作
